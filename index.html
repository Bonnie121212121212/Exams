Section A: C# Data Types Matching [12 Marks • 3 Marks Each]
Question 1: Matching Themed Literals to C# Types (12 Marks)
Write the correct letter (A, B, C, or D) in the center column to match each value with its valid C# type keyword.
Literal Value Your Choice (A-D) C# Keyword
"Nya! :3" A) int (Whole integer)
4 (Number of paws) B) string (Text data)
true (isGay) C) double (Decimal value)
158.5 (Height in cm) D) bool (Logical true/false)
Answers: "Nya! :3" → B (string) • 4 → A (int) • true → D (bool) • 158.5 → C (double).
Section B: Multiple Choice [12 Marks • 4 Marks Each]
Question 2: Correct Console Output Method (4 Marks)
Which line of C# code correctly prints UwU to the terminal screen on its own line?
Answer: (B). In C#, Console.WriteLine("UwU"); is the standard method for writing a line of text to standard output.
Question 3: Declaring a Boolean Variable (4 Marks)
Which statement correctly declares a boolean variable named isFurry set to true?
Answer: (B). C# uses the bool keyword and lowercase true / false literals.
Question 4: Legal Variable Identifiers (4 Marks)
Which of the following variable names is invalid in C#?
Answer: (D) 2catboys. Variable identifiers in C# cannot begin with a numeric digit.

Section C: Output Tracing [12 Marks • 4 Marks Each]
Question 5: String Joining vs Integer Addition (4 Marks)
Write the exact console output of the following two lines: 
Console.WriteLine("Cat" + "boy");
Console.WriteLine(2 + 2);
Output:
Catboy (String concatenation)
4 (Arithmetic integer addition)
Question 6: Variable Reassignment (4 Marks)
Trace what value is printed when this code snippet runs: 
string outfit = "maid dress";
outfit = "oversized hoodie";
Console.WriteLine("Outfit: " + outfit);
Output: Outfit: oversized hoodie
Question 7: Single-Line Comments (4 Marks)
What value is printed by this snippet? 
int ears = 2;
// ears = 4;
Console.WriteLine(ears);
Output: 2 (The reassignment is commented out with // and ignored by the compiler).
Section D: Syntax Fixing & Code Writing [14 Marks]
Question 8: Fixing Syntax Errors (4 Marks)
The following line fails to compile in C#. Explain what is missing, and write the corrected line: 
Console.WriteLine("Nya! Meow")
Explanation: The line lacks a terminating semicolon.
Fixed line: Console.WriteLine("Nya! Meow");
Question 9: Storing and Printing a Fursona (5 Marks)
Write two complete lines of C# code:
  1. Declare a string variable named fursona and set it to "Fennec Fox".
  2. Print the variable to the console using Console.WriteLine().
Example Solution: 
string fursona = "Fennec Fox";
Console.WriteLine(fursona);
Question 10: Tail Math Calculation (5 Marks)
Write three complete lines of C# code:
  1. Declare an int variable named catboys with value 3.
  2. Declare an int variable named furries with value 2.
  3. Print the total sum of catboys + furries to the console.
Example Solution: 
int catboys = 3;
int furries = 2;
Console.WriteLine(catboys + furries);
